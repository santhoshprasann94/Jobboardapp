# Job Board Application

A full-stack Job Board application built using Spring Boot and React.

## Live Demo

### Frontend (Vercel)
https://jobboardapp-ebon.vercel.app

### Backend (Render)
https://jobboardapp-f7n0.onrender.com

## GitHub Repository

https://github.com/santhoshprasann94/Jobboardapp

## Tech Stack

### Frontend
- React
- Vite
- Axios
- CSS

### Backend
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

## Features

- Add Job
- View Jobs
- Edit Job
- Delete Job
- Search Jobs
- Responsive UI

## Deployment

- Frontend: Vercel
- Backend: Render (Docker)
- CI/CD: GitHub Actions
